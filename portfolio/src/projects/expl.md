# Expanded Learning Program Attendance Tracker

## Summary

Cross-platform attendance data pipeline and Zoho Analytics dashboard that consolidates Expanded Learning program records for Safe Passages.

## Highlights

- Automated attendance data collection by building Playwright (Python) scripts to replace manual downloads from the America Learns platform, reducing entry and export errors.
- Designed a cross-platform data pipeline that syncs attendance data from multiple sources into Zoho Analytics as a single source of truth, applying relational database normalization to keep records consistent across schools and programs.
- Built interactive attendance dashboards and reports in Zoho Analytics, surfacing trends by school and date, with program-level summary statistics so leadership can monitor sites without requesting ad hoc pulls.
